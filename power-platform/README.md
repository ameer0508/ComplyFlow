# Microsoft Power Platform Documentation & Artifacts

This directory will store design specifications, schemas, exported solution files, and documentation for Microsoft Power Platform components.

---

## 📁 Subdirectory Organization

- `sharepoint/`: SharePoint Online List schema definitions, field types, and view configurations.
- `power-apps/`: Canvas App wireframes, formula specifications, and exported `.msapp` solution packages.
- `power-automate/`: Flow logic documentation, trigger definitions, and exported JSON workflow definitions.
- `power-bi/`: Power BI report templates (`.pbit`), DAX calculations, and dashboard layout documentation.

> **Status:** All Power Platform components are currently in the planning stage. No active cloud configurations have been deployed yet.
